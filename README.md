# FastAPI Azure App — Banking System

## Overview
A FastAPI banking backend designed to run on Azure Container Apps. Features OAuth 2.0 authentication, bank account lifecycle management with Cosmos DB, soft-delete on account closure, role-based admin access, and Azure Application Insights telemetry via OpenTelemetry.

## Bank Account API

### Customer endpoints (Bearer token required)
| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/accounts` | Create a new account. Returns a server-generated 10-digit account number. |
| `GET` | `/accounts` | List own active accounts. |
| `GET` | `/accounts/{account_number}` | Get a single active account. |
| `PUT` | `/accounts/{account_number}` | Update mutable fields (currency). |
| `POST` | `/accounts/{account_number}/close` | Soft-delete (close) an account. |
| `POST` | `/statements/email` | Send statement e-mail for an effective one-month period. |

### Admin endpoints (bank_employee role required)
| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/admin/accounts` | List all accounts, including closed ones. |
| `GET` | `/admin/accounts/{account_number}` | Get any account including closed ones. |

### Account lifecycle
- **Creation** — unique 10-digit numeric account number generated server-side (UUID entropy); stored as Cosmos DB `id` and partition key.
- **Closure** — soft-delete: `status=CLOSED`, `is_deleted=true`, `closed_at` and `closure_reason` recorded. Data is permanently retained.
- **Admin access** — `bank_employee` role (JWT `role` claim) can access all accounts including closed ones via `/admin/accounts`.

### JWT roles
Include `role` in the JWT payload:
- `"role": "customer"` — standard account operations
- `"role": "bank_employee"` — additionally grants access to admin endpoints

## Environment Variables
| Variable | Description |
|----------|-------------|
| `COSMOS_ACCOUNT_URL` | Cosmos DB account endpoint, e.g. `https://<account>.documents.azure.com:443/` |
| `COSMOS_DB_NAME` | Name of the Cosmos DB database |
| `APPLICATIONINSIGHTS_CONNECTION_STRING` | Azure Monitor connection string |
| `SMTP_HOST` | SMTP server host used for statement e-mail delivery |
| `SMTP_PORT` | SMTP server port |
| `SMTP_SENDER_EMAIL` | Sender e-mail address for statement notifications |
| `SMTP_USERNAME` | Optional SMTP username for authenticated relays |
| `SMTP_PASSWORD` | Optional SMTP password for authenticated relays |
| `SMTP_USE_TLS` | Optional TLS toggle (`true` by default) |
| `SMTP_TIMEOUT_SECONDS` | Optional SMTP timeout in seconds (`15` default) |

## Setup Instructions
1. **Clone the Repository**
   ```bash
   git clone <repository-url>
   cd fastapi-azure-app
   ```

2. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Application**
   ```bash
   COSMOS_ACCOUNT_URL=https://<account>.documents.azure.com:443/ \
   COSMOS_DB_NAME=<dbname> \
   uvicorn src.main:app --reload
   ```

4. **Access API docs**
   - Swagger UI: `http://localhost:8000/docs`
   - ReDoc: `http://localhost:8000/redoc`

## Authentication
OAuth 2.0 Bearer token. Obtain a token from `/token` (dev only; replace with Entra ID in production).

```bash
curl -X POST http://localhost:8000/token \
  -d "username=johndoe&password=secret"
```
